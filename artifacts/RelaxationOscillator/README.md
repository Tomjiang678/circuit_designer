# Relaxation Oscillator — 100-Point Test Matrix

Date: 2026-10-20

## Scope

100 deterministic relaxation-oscillator designs generated by `ComparatorDesignEngine`.
Each point is validated by `ComparatorCircuitVerifier`, the RT/CT timing pair is read back
from the generated CircuitGraph, and the oscillator's actual frequency/duty are compared
with the request.

## Coverage

| Dimension | Values |
|---|---|
| Target frequency | 10, 25, 50, 100, 250, 500, 1 k, 5 k, 20 k, 100 kHz |
| Supply / output | 0/+2.5 V, 0/+3.3 V, 0/+5 V, 0/+9 V, 0/+12 V, 0/+15 V, ±2.5 V, ±5 V, ±12 V, ±15 V |
| Duty cycle | 20, 25, 30, 40, 45, 50, 60, 70, 75, 80 % |
| Timing R range | 100 Ω–1 MΩ, 1 k–1 MΩ, 1 k–100 k, 10 k–1 M, 100 Ω–100 k, 4.7 k–470 k, 1 k–470 k, 10 k–470 k, 100 Ω–1 M, 2.2 k–2.2 M |
| Resistor series | E96, E48, E24 (rotating) |
| Standard-value optimization | 50 points optimized, 50 points continuous |

## Acceptance criteria

- Engine result is `Pass` or `Warning` (not `Failed`).
- All independent verification metrics pass.
- Frequency error within the series acceptance window:
  - E96 / continuous: 2 %
  - E48: 3 %
  - E24: 5 %
  (The independent verifier uses the same series-aware tolerance.)
- Duty-cycle error ≤ 1 percentage point.
- CircuitGraph contains the `RT` resistor and `CT` capacitor.

### Warning point

Point **75**: 250 Hz, 75 % duty, E24, optimized, timing range 100 Ω–100 kΩ.

- Actual: 243.5514593 Hz / 75.12375885 %
- Frequency error: −2.57942 %
- Duty error: +0.123759 points
- Status: **Warning** — within the E24 5 % acceptance window, but above the 2 % target.
- The engine emits: “The selected E24 timing pair gives a 2.58 % frequency error. E24/E48
  tolerate a coarser standard-value grid; choose E96 or disable standard-value
  optimization for a 2 % target.”

This is the expected standard-value limitation of E24, not a synthesis failure: the
selected pair is the best E24 product in the allowed range. E96 or continuous design
for the same point meets the 2 % window.

## Fix found by this matrix

Two continuous-design points (100 Hz/70 % and 5 kHz/70 %, range 10 kΩ–1 MΩ/470 kΩ)
previously failed because a continuous resistance landed a few ulps below the inclusive
10 kΩ minimum. `Nearby()` now accepts a 1e-9 relative numerical boundary tolerance and
clamps the value into the requested range.
